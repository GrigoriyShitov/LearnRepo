# Практическое задание 7

## Задание

- Сделать новые **docker-compose.yml** для сервисов, либо “довести до ума” данные в примере до полноценного вида
- В *Opensearch Dashboard* создать индекс `dev-index`
- Сделать так, чтобы поле `hostname` стало читабельным (=имя контейнера)
- Предварительно “нагенерить” логи, затем в *Opensearch Dashboard* сделать запрос с фильтрацией:
  \- по полю `module/name/hostname/подобные` (фильтрация по источнику)
  \- уровень логов != ERROR (фильтрация по важности)
  \- сам `message` содержит определенное слово (фильтрация по содержимому пейлода)
- \*Подключить любой из уже имеющихся в проекте сервисов к *fluentd*, или просто любой новый `*.log` файл

## Проверка результата

- При запуске приложений видно JSON-логи, в stdout и в файлах
- После создания индекса в Opensearch Dashboard видны те же самые логи
- В Minio появляются архивы с новыми логами

## Отчетность

- файл `docker-compose.yml`
- файл `docker-compose-infra.yml`
- Код приложения, если он отличается от примера по умолчанию
